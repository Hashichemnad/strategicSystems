# المزامنة الاحتياطية مع Salesforce: الإعداد والمراقبة والتحويل والعودة إلى الاحتياط

للمسؤولين (المرحلة 23، ملحق المتطلبات §G، القرارات 0200–0208). الشاشات: **الإعدادات ← التكامل ← مزامنة Salesforce**.

ما دام Salesforce هو النظام **الأساسي**، يتلقى هذا النظام نسخة منتظمة **في اتجاه واحد** من بياناته (الإدارات، والمستخدمين بعد مطابقتهم
مع الموظفين، والفرق، والمشاريع وسائر الأنظمة، والملفات، وسجل الاعتمادات) ليتمكن من تولي العمل إذا تعذّر الوصول إلى Salesforce.
**لا يكتب هذا النظام في Salesforce أبداً**: لا يرسل الموصل إلا طلبات قراءة (ومهام *استعلام* Bulk API 2.0). وتكون السجلات المتزامنة
**للقراءة فقط** هنا ما دام Salesforce أساسياً. وبعد أي انقطاع يُعيد المستخدمون إدخال التغييرات التي تمت هنا في Salesforce يدوياً،
بالاستعانة بـ **تقرير تغييرات فترة الانقطاع**.

## 1. في Salesforce: الشهادة والتطبيق المتصل ومستخدم التكامل

1. **أنشئ زوج مفاتيح وشهادة** (على جهاز المسؤول، لا على الخادم):
   ```bash
   openssl req -x509 -newkey rsa:2048 -sha256 -days 730 -nodes -keyout strategy-sync.key -out strategy-sync.crt -subj "/CN=Strategy standby sync"
   ```
   يُرفع الملف `strategy-sync.crt` إلى Salesforce، ويُدخل `strategy-sync.key` (المفتاح الخاص بصيغة PEM) في هذا النظام في الخطوة 2.4 ثم
   يُحذف من الجهاز. تُرفض المفاتيح الأقل من 2048 بت.
2. **مستخدم التكامل**: Setup ← Users ← New user، بترخيص *Salesforce Integration* (أو ترخيص عادي إن لم يتوفر)، وملف
   *Minimum Access – API Only Integrations*. لا تستخدم حساب شخص.
3. **مجموعة صلاحيات للقراءة فقط** («Strategy standby sync — read only») تُسند إلى مستخدم التكامل:
   - صلاحية **Read** (و*View All* حتى لا تُخفي قواعد المشاركة سجلات) على كل كائن مطابق: `Department__c` و`User` و`Contact`
     و`Project_Team__c` و`Project_Team_Association__c` و`PMS_Project_Request__c` و`PMS_Project__c` و`PMS_Work_Plan__c` و`PMS_Project_Kpi__c`
     و`PMS_Project_Risk__c` و`PMS_Project_Stakeholder__c` و`PMS_Project_Planning_Item__c` و`PMS_Challenges_Constraints__c` و`PMS_Change_Request__c`
     و`PMS_Contract__c` و`PMS_Lesson_Learned__c` و`PMS_Team_Meeting__c`، وكائنات الأداء (`Org_Kpi_Goal__c` و`Org_Kpi_Measure__c` و`Org_Kpi_Process__c`)،
     و`Risk_Kpi_Relation__c`، وكائنات المخاطر والتدقيق وخطط الإجراءات التصحيحية والمقارنة المعيارية وسجل الوثائق والملكية الفكرية والمهام في مؤسستك.
   - أمان الحقول **Read** على كل حقول هذه الكائنات (وإلا سيعرضها محرر المطابقة كحقول غير معروفة).
   - الملفات: امنح المستخدم الوصول إلى المكتبات أو السجلات التي يجب نسخ ملفاتها.
   - لا تمنح أبداً *Create* أو *Edit* أو *Delete* أو *Modify All*: لا تحتاجها المزامنة.
4. **التطبيق المتصل (Connected App)**: Setup ← App Manager ← New Connected App: فعّل *Enable OAuth Settings*، وعنوان الرجوع
   `https://localhost/unused` (غير مستخدم)، و**Use digital signatures** ← ارفع `strategy-sync.crt`، ونطاقات OAuth:
   **Manage user data via APIs (api)** و**Perform requests at any time (refresh_token, offline_access)**. احفظ ثم *Manage* ← *Edit Policies*:
   **Permitted users: Admin approved users are pre-authorized**، وأضف مجموعة الصلاحيات (أو ملف مستخدم التكامل). انسخ **Consumer Key**.
5. سجل تغييرات الحقول: إن أردت عرضه في لوحة «سجل المصدر» فأبقِ *Track Field History* مفعلاً للكائنات، وامنح مستخدم التكامل صلاحية قراءة
   كائنات `…__History`.

## 2. في هذا النظام: الاتصال

1. الإعدادات ← التكامل ← **مزامنة Salesforce** ← **الاتصال**.
2. **عنوان تسجيل الدخول**: `https://login.salesforce.com` (الإنتاج) أو `https://test.salesforce.com` (بيئة الاختبار) أو عنوان My Domain. HTTPS فقط.
3. **مفتاح المستهلك** (من التطبيق المتصل)، و**اسم مستخدم** التكامل، و**إصدار الواجهة البرمجية** (الافتراضي `v62.0`).
4. **المفتاح الخاص**: الصق محتوى `strategy-sync.key` (PEM). يُخزَّن مشفراً ولا يُعرض مرة أخرى — تُعرض **بصمته** فقط لتقارنها بالشهادة.
   استبدله قبل انتهاء الشهادة (كرر الخطوة 1.1 وارفع الشهادة الجديدة إلى التطبيق المتصل أولاً).
5. **حد Bulk** (الافتراضي 2000): التغييرات الأكبر منه تُقرأ بـ Bulk API 2.0 والأصغر بـ REST. التحميل الأولي يستخدم Bulk API 2.0 دائماً.
6. **حزمة المطابقة**: *ADoF Salesforce* (مرفقة مع النظام).
7. **اختبار الاتصال**: يسجّل الدخول بطريقة JWT bearer ويقرأ حدود الواجهة البرمجية وقائمة الكائنات. أصلح أي رسالة تظهر قبل المتابعة
   (مثل *user hasn't approved this consumer* ← سياسات الخطوة 1.4).

## 3. المطابقات (محرر المطابقة)

تطابق حزمة ADoF كل كائن في Salesforce مع نوع سجل هنا. الكائنات التي لم يكن مستخدم التكامل يراها عند إعداد الحزمة مُعلّمة **مبدئية** ومعطّلة.

1. تبويب **المطابقات** ← افتح كائناً. يعرض الجانب الأول **قائمة حقول Salesforce الحية** (الأنواع وقيم القوائم)، والجانب الآخر مطابقات
   الحقول: حقل المصدر ← حقل الهدف، والنوع (مباشر، قائمة ← رمز، مرجع ← سجل متزامن، شخص ← موظف، نوع السجل، قيمة ثابتة)، وجداول القيم،
   والتحويلات (إزالة المسافات، أحرف كبيرة/صغيرة، نسبة مئوية ← نسبة، التاريخ فقط، HTML ← نص، اقتطاع، نعم/لا)، والإلزامية.
2. وأيضاً: القيم الافتراضية للحقول الفارغة، وقائمة الحقول المتجاهلة، وشرط التصفية (SOQL)، وقالب المعرّف الخارجي (مثل
   `{Id}-{year:End_Date__c}` لـ «تقييم واحد لكل سنة»)، وترتيب التحميل (الأب قبل الابن).
3. **تحقّق**: يفحص كل حقل وقيمة قائمة مقابل الوصف الحي. لا يُفعّل الكائن إلا بعد نجاح التحقق، وأي تعديل يلغي التأكيد. وتعرض التحذيرات
   قيم القوائم الجديدة التي لا رمز لها بعد، والحقول المخصصة غير المطابقة وغير المتجاهلة.
4. **تصدير / استيراد** الحزمة (JSON) للاحتفاظ بنسخة أو نقلها بين التركيبات. لا تُصدَّر الأسرار ولا علامات آخر مزامنة.
5. **الأشخاص**: يُطابَق مستخدمو Salesforce وجهات الاتصال مع الموظفين الحاليين بالبريد الإلكتروني ثم الرقم الوظيفي ثم معرّف الاتحاد.
   حمّل الموظفين أولاً (استيراد الهيكل التنظيمي). ويذهب غير المطابَقين إلى قائمة الاستثناءات.

## 4. التحميل الكامل الأول

1. **تفعيل** من تبويب الحالة (يتطلب نجاح اختبار الاتصال). يصبح الوضع **احتياطي**.
2. **تحميل كامل**: يقرأ كل كائن مفعّل بـ Bulk API 2.0 حسب ترتيب التحميل، ويعرض تبويب الحالة التقدم لكل كائن.
3. افتح **الاستثناءات** وعالج ما ظهر:
   - *قيمة غير مطابقة* ← **طابق القيمة** (تضيف القيمة ← الرمز إلى جدول قيم الحقل) فيُعاد معالجة السجل فوراً.
   - *مستخدم غير معروف* ← **طابق الشخص** (اختر الموظف) ثم تُعاد معالجة السجلات التي تشير إليه.
   - *الأب غير موجود* ← يُحل غالباً تلقائياً عند وصول الأب؛ وإلا فراجع مطابقة الأب.
   - *قيمة غير صالحة* / *حقل إلزامي فارغ* ← صحّح المطابقة (تحويل أو قيمة افتراضية) ثم **أعد المعالجة**.
4. إعادة التشغيل آمنة: تُطابَق السجلات بمعرّف Salesforce، فلا يُنشأ شيء مرتين.

## 5. الجدول الزمني

تبويب **الجدول**: كل N ساعات (من وقت محدد في اليوم)، أو يومياً في وقت محدد، أو أسبوعياً في أيام محددة — بتوقيت التركيبة، مع عرض
التشغيلات الخمسة القادمة. ويحدد حقل *متأخرة بعد* (بالدقائق) متى تُعدّ المزامنة متأخرة. **زامن الآن** يشغّل مزامنة تزايدية فوراً.
تقرأ المزامنة التزايدية السجلات المتغيرة منذ آخر تشغيل فقط (`SystemModstamp` مع تداخل 5 دقائق)، وتُعلَّم السجلات المحذوفة في Salesforce
بـ **«محذوف في Salesforce»** هنا ولا تُحذف أبداً.

## 6. المراقبة

- تبويب **الحالة**: الوضع، وآخر تشغيل (الحالة والمدة)، والتشغيل القادم، واستهلاك الواجهة البرمجية من الحد اليومي، والأعداد لكل كائن
  (أُنشئ، حُدّث، دون تغيير، حُذف، فشل، تعارض)، والاستثناءات المفتوحة.
- تبويب **التشغيلات**: السجل التاريخي وسجل كل تشغيل.
- **تنبيهات بريدية** (بالعربية والإنجليزية) لحاملي صلاحية *إدارة المزامنة*: عند فشل تشغيل، وعند تأخر المزامنة (مرة لكل فترة تأخر).
- **صفحة السلامة** (الإعدادات ← السلامة ← التكامل): مزامنة Salesforce سليمة / متأخرة / فاشلة / استثناءات / هذا النظام أساسي.
- يتوقف التشغيل إذا بقي أقل من 10% من طلبات الواجهة البرمجية اليومية (قابل للضبط).

## 7. ما دام Salesforce أساسياً (الوضع الاحتياطي)

- تظهر السجلات المتزامنة بشارة **«متزامن من Salesforce — للقراءة فقط»**، ويُرفض أي تغيير عليها من كل القنوات (الشاشات وواجهة REST
  وMCP والاستيراد والمهام المجدولة) برسالة واضحة، ولا يمكن تقديمها للاعتماد أو اتخاذ قرار عليها.
- تُعلَّق المهام المجدولة والإشعارات الخاصة بأنظمة العمل (لا تذكيرات ولا رسائل مكررة)، وتبقى لوحات المؤشرات والتقارير متاحة.
- تعرض صفحة السجل **سجل الاعتمادات** و**سجل تغييرات الحقول** من Salesforce تحت *المراجع الخارجية ← سجل المصدر* (للعرض فقط).
- السجلات المنشأة هنا وغير الآتية من Salesforce تبقى قابلة للتعديل.

## 8. دليل التحويل — «اجعل هذا النظام أساسياً»

استخدمه فقط عندما يتعذر الوصول إلى Salesforce مدة تستوجب استمرار العمل هنا.

1. تأكد من الانقطاع مع مسؤول Salesforce واتفقا على وقت التحويل، وأبلغ المستخدمين.
2. الإعدادات ← التكامل ← مزامنة Salesforce ← **التحويل** ← **اجعل هذا النظام أساسياً**: أدخل **السبب** و**رمز التحقق** (تطبيق المصادقة
   أو *أرسل رمزاً بالبريد*). تحتاج صلاحية *التحويل* (مسؤول التكامل، والتحقق بخطوتين إلزامي).
3. ما يحدث: تتوقف المزامنة، وتُفتح السجلات للتعديل، وتعمل مسارات الاعتماد والمهام والإشعارات كالمعتاد، وتبدأ **فترة انقطاع**، وتأخذ
   السجلات التي كان اعتمادها معلقاً في Salesforce حالة **«مطلوب إعادة التقديم»** — يعيد صاحبها تقديمها هنا ويتخذ المعتمدون القرار هنا
   (ويبقى سجل اعتمادات Salesforce ظاهراً).
4. يستمر العمل هنا، ويُسجَّل كل تغيير في سجل التدقيق ويظهر في **تقرير تغييرات فترة الانقطاع** (تبويب التحويل) مجمّعاً حسب النظام والسجل،
   مع القيم السابقة ← الجديدة ومعرّف Salesforce.

## 9. دليل العودة إلى الوضع الاحتياطي

عندما يعود Salesforce متاحاً:

1. **أوقف** العمل الجديد هنا أثناء إعادة الإدخال (اتفق على وقت مع المستخدمين).
2. افتح **تقرير تغييرات فترة الانقطاع** و**صدّره** (Excel أو PDF، بالعربية أو الإنجليزية) وأعد إدخال التغييرات في Salesforce، وعلّم
   **أُعيد إدخاله** لكل سجل. السجلات المنشأة هنا ليس لها معرّف Salesforce: أنشئها في Salesforce.
3. **العودة إلى الوضع الاحتياطي** (يجب أن يكون التقرير قد صُدّر أو أُقرّ). تُستأنف المزامنة وتعود السجلات المتزامنة للقراءة فقط.
   وتبقى السجلات التي تغيّرت هنا أثناء الانقطاع محمية: إذا أرسل Salesforce نسخة أحدث منها تنتظر **كتعارض**.
4. **التعارضات**: اختر لكل سجل **الإبقاء على النسخة المحلية** (تُتجاهل نسخة Salesforce حتى إغلاق فترة الانقطاع — عندما لم يُعَد إدخال
   التغيير في Salesforce بعد) أو **اعتماد نسخة Salesforce** (تُطبق فوراً — عندما يحمل Salesforce البيانات الصحيحة الآن).
5. **أغلق فترة الانقطاع** عندما لا يبقى تعارض معلق. ومن بعدها يكون Salesforce هو المرجع لكل السجلات من جديد.
6. إذا تعطل Salesforce مرة أخرى قبل الإغلاق فاستخدم **اجعل هذا النظام أساسياً** مجدداً: تستمر فترة الانقطاع نفسها.

## 10. معلومات مفيدة

- لا تكتب المزامنة في Salesforce أبداً؛ ولا يحتاج مستخدم التكامل إلا صلاحيات القراءة.
- لا يظهر المفتاح الخاص ولا رموز الوصول ولا بيانات Salesforce في السجلات التقنية؛ وكل إجراء للمسؤول مسجّل في سجل التدقيق
  (`integration.sync.*`)، وكل تغيير متزامن مدقَّق بقناة **sync**.
- للانتقال إلى مؤسسة Salesforce أخرى: صدّر الحزمة، وغيّر الاتصال، وتحقق من كل كائن، ثم شغّل تحميلاً كاملاً.
