## Fixes found along the way
- Audit timestamps were returned with 100 ns precision but stored with 1 µs, so a later read differed from the create response. They are now truncated.
- The Radix toast screen-reader label was always English; it is now translated.
- The RTL guard missed bare `border-r` / `rounded-l`; its own test caught that and the rule was fixed.
- Vitest 3 had critical advisories; moved to Vitest 4.1.12.

## Known gaps (by design: later phases)
- No sign-in yet (Phase 1). The sample API runs under the Development/Testing access placeholder; per-role/scope negative tests come with Phase 2.
- Module switch reads configuration (`Modules:<Name>:Enabled`). The Settings centre, lookups, numbering and translation overrides come in Phase 2. The sidebar is not yet filtered by access, and the "UI kit" entry is visible to everyone until then.
- Only `created_*` / `updated_*` are stamped. The field-level, hash-chained audit trail, files, notifications, Quartz and the outbox come in Phase 3.
- Arabic search normalisation (`*_search` columns, trigram/full-text) is not in the sample; it uses `ILIKE`. It arrives with Platform.Search.
- Idempotency-key header on submit/approve endpoints: with the approval engine (Phase 4). PAT / OAuth exemptions from antiforgery: Phases 1 and 5.
- ASP.NET Core Data Protection keys are not yet persisted (startup warning). This is needed for Phase 1 cookies and secrets.
- Reverse-proxy forwarded headers, backup/upgrade scripts, automated WCAG audit (axe): Phase 18. ESLint jsx-a11y runs now.
- The GitHub Actions workflow has not run on GitHub yet; it starts when the pull request is opened.

## How to demo
```bash
docker compose -f deploy/docker-compose.yml up -d postgres gotenberg mailpit
dotnet run --project src/Host/Strategy.Host          # http://localhost:5080
cd web && npm ci && npm run dev                       # http://localhost:5173
```
1. Open http://localhost:5173. The app opens in Arabic (RTL) unless the browser is English. Use the **English / العربية** button: the layout mirrors instantly, with no reload.
2. **الوحدة النموذجية / Sample module**: create an item (try saving with no name, then a 201-character name), search, sort, edit, deactivate.
   Edit the same item in two tabs and save both: the second save gets the "changed by someone else" message (409).
3. **مكونات الواجهة / UI kit**: every shared component; switch the theme (light / dark) from the top bar.
4. http://localhost:5080/openapi/v1.json, http://localhost:5080/health/ready, and `curl -I http://localhost:5080/` for the security headers.
5. Containers only: `docker compose -f deploy/docker-compose.yml --profile app up -d --build` → http://localhost:8080
   (the sample module is off in production configuration; set `MODULE_SAMPLE_ENABLED=true` to see it; the API then answers 403, because production access is fail-closed until Phase 2).
