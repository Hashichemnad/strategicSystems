# Version 1.0.0

First release of the Integrated Strategy System — a self-hosted, bilingual (Arabic / English) strategy management suite: one application,
one database and one sign-in for eleven systems.

## What is included
- **Systems:** Portfolio Management (requests, project lifecycle, change control, Agile / Hybrid, PM standards, Gantt, status report,
  the **Wasel** vendor portal), Performance Management (KPI), Risk Management, Teams Management, Task Management, Requests with Document
  Registry and Intellectual Property, Benchmarking, Corrective Action Plan and Audit Management.
- **Shared platform:** organisation and employees with history, sign-in with two-step verification and single sign-on (Entra ID, ADFS,
  UAE Pass, SAML, LDAP), access by system, role, data scope and record, configurable approval chains with delegation and deadlines in
  working time, tamper-evident audit trail with a History tab on every record, bilingual notifications, files with versions and virus
  scanning.
- **Dashboards and reporting:** My Work, role and system dashboards, executive dashboard with the department scorecard, dashboard and
  report builder, scheduled e-mail delivery, Excel / PDF export.
- **AI (optional) and MCP:** drafts and summaries with the provider you choose (or a model on your own servers); people always decide. The
  MCP server lets Claude and other MCP clients work with the system as the signed-in user, with the same permissions.

## New for installation and operation
- One-command installer for Linux and Windows (Docker), first-run **setup wizard**, optional removable **demo data**.
- **Backup, verified restore and upgrade** scripts; **System health** page (Settings); this *About* window.
- Vendors can sign in to Wasel with **UAE Pass** when it is switched on (a second factor is still required).
- Passwords that are among the most common ones are refused.

## Before you upgrade from a pre-release build
- Scheduled reminders, digests and escalations now run on their schedules — users may receive reminders they did not receive before.
- Take a backup; the upgrade script does this for you.

## Known limitations
- Live dashboard figures for people who see only their own or their team's records show no comparison with the previous period ("—") for
  figures that are a count at a point in time.
- There is no global search box in the top bar; search is available in each list, in *Ask the system* (AI) and through MCP.
- Rich text is shown as plain text; public links for public documents are not offered; a few lists offer the first 200 entries only
  (KPI picker).
- The audit trail is kept forever (no retention purge in this version).

The administrator, installation and user guides (Arabic and English) are delivered with this version.
