# Version 1.0.0

First release of the Integrated Strategy System.

## Highlights
- Eleven systems on one platform: Portfolio Management (with Agile / Hybrid and the Wasel vendor portal), Performance Management, Risk
  Management, Teams, Requests, Document Registry, Intellectual Property, Benchmarking, Corrective Action Plan, Audit Management and Tasks.
- Executive, system and role dashboards, report builder and scheduled delivery.
- AI assistance (optional) and an MCP server for Claude and other MCP clients.
- First-run setup wizard, health page, backup / restore and upgrade scripts.

The full release notes and known limitations are in the release documentation delivered with this version.
