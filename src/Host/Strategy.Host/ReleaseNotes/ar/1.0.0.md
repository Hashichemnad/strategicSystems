# الإصدار 1.0.0

الإصدار الأول من نظام الاستراتيجية المتكامل.

## أبرز ما فيه
- أحد عشر نظامًا على منصة واحدة: إدارة المحافظ والمشاريع (مع المنهجية المرنة والهجينة وبوابة الموردين «واصل»)، وإدارة الأداء، وإدارة
  المخاطر، والفرق، والطلبات، وسجل الوثائق، والملكية الفكرية، والمقارنة المعيارية، وخطة الإجراءات التصحيحية، وإدارة التدقيق، والمهام.
- لوحات معلومات تنفيذية وللأنظمة وللأدوار، ومنشئ التقارير والإرسال المجدول.
- مساعدة الذكاء الاصطناعي (اختيارية) وخادم MCP لـ Claude وغيره من عملاء MCP.
- معالج الإعداد الأولي وصفحة سلامة النظام ونصوص النسخ الاحتياطي والاستعادة والترقية.

ملاحظات الإصدار الكاملة والقيود المعروفة موجودة في وثائق الإصدار المرفقة بهذا الإصدار.
